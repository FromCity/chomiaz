
Описание

Backend-сервис, который принимает сообщения от внешнего чат-бота, сохраняет их в базу данных, обрабатывает в фоне через очередь задач и предоставляет API для просмотра истории обращений пользователей.

Для запуска проекта используйте команду:
docker-compose up -d
Миграции запустятся автоматически
Воркер запустится автоматически
Тесты запустятся автоматически
Чтобы запустить тесты вручную используйте команду:
docker compose run --rm tests

Примеры API-запросов:

Приём webhook-сообщения
POST /api/webhooks/messages
Пример входящего сообщения:
{
  "external_message_id": "msg-10001",
  "user_id": "user-42",
  "text": "Хочу узнать статус заказа 12345",
  "created_at": "2026-05-13T10:00:00Z"
}

Пример успешного ответа:
{
  "id": 1,
  "status": "received"
}

Пример ответа при повторном webhook:
{
  "id": 1,
  "status": "processed",
  "duplicate": true
}

API просмотра истории сообщений пользователя
GET /api/users/{user_id}/messages
Endpoint возвращает историю сообщений пользователя, отсортированную от старых к новым.

Пример ответа:
[
  {
    "id": 1,
    "external_message_id": "msg-10001",
    "user_id": "user-42",
    "text": "Хочу узнать статус заказа 12345",
    "status": "processed",
    "message_type": "order_status",
    "response_text": "Ваш запрос по заказу принят в обработку",
    "created_at": "2026-05-13T10:00:00Z",
    "processed_at": "2026-05-13T10:00:05Z"
  }
]

API просмотра одного сообщения

GET /api/messages/{id}

Пример ответа:
{'id': 3, 'external_message_id': 'msg-test-5', 'user_id': 'user-42', 'text': 'Хочу узнать статус заказ 12345', 'status':
'processed', 'message_type': 'order_status', 'response_text': 'Ваш запрос по заказу принят в обработку', 'error_text':
'', 'created_at': '2026-05-13T10:00:00Z', 'received_at': '2026-05-18T13:27:18.047519Z', 'processed_at':
'2026-05-18T13:27:18.222660Z'}
Если сообщение найдено, то API вернет ошибку 404 Сообщение не найдено.

Архитектура решения сделана на MVC. Использованы слои serializers/forms, views, models.
Данное решение предназначено для небольших нагрузок.

В procdution-версии можно использовать системы кэширования, оптимизацию БД, обработка cors
перенести SECRET_KEY в файл, Отключить режим отладки (DEBUG = False).
